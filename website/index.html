AI part generation

Describe it. Get a part you can edit.

The AI doesn't hand you a frozen mesh. It writes a parametric model with sizes you can change, and if its first try fails, it fixes its own mistake.

  • →Claude, GPT, Gemini, and Llama, or a free local model with Ollama
  • →Ask for changes: "make it 20% taller and add a slot"
  • →Your key stays in your browser
  Generate a part with AI
width = 70angle = 65°slot = 14
const base = cad.box(p.width, 60, 6);
const back = cad.turn(cad.box(p.width, 6, 80), 90 - p.angle, [1, 0, 0]);
const lip = cad.move(cad.box(p.width, 6, 14), 0, -27, 4);
// cut a slot for the charging cable
const slot = cad.move(cad.box(p.slot, 70, 20), 0, 0, -1);
return cad.subtract(cad.union(base, back, lip), slot);
